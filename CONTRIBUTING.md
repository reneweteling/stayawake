# Contributing to StayAwake

StayAwake is source-available under the [PolyForm Noncommercial License 1.0.0](LICENSE.md). You are welcome to read the code, build it for yourself, and use it for any noncommercial purpose. Selling it, bundling it into a product, or using it inside a business needs a separate license.

## Pull requests are not accepted

This is a one-person project and I keep the copyright on every line. A pull request is closed automatically with a note pointing here. Nothing personal.

## What is welcome

- Bug reports: [open an issue](https://github.com/reneweteling/stayawake/issues/new?template=bug.yml). Paste the version from Settings, About. If a safety rule did not release sleep when it should have, say which rule and attach the event log.
- A rule or sensor StayAwake does not have yet: [open an issue](https://github.com/reneweteling/stayawake/issues/new?template=feature.yml) with the situation and what should release sleep.
- Questions: an issue is fine too.

## Building from source

See the README. `./scripts/build.sh` produces an ad-hoc signed `build/StayAwake.app` for your own machine.
